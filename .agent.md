# Agent rules

1. **No leading-underscore names** — Do not use `_` prefixes on functions, methods, or variables (e.g. `_helper`, `_internal`). Use plain names; framework-required dunders (e.g. `__init__`) are fine.

2. **No unnecessary comments** — Do not add comments that only restate the code. Prefer clear naming instead. Only comment where behavior is non-obvious, externally constrained, or unsafe to change.
